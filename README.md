# ⚽ Bolão Copa 2026 - Vini

Plataforma de bolão para a Copa do Mundo 2026 com sistema de apostas, ranking ao vivo e premiações.

## 📋 Características

- 🔐 Sistema de login seguro com convites
- 🎯 Palpites de placares com sistema de pontuação
- 🌟 Apostas extras (campeão, vice, artilheiro)
- 📊 Ranking atualizado em tempo real
- 🏆 Sistema de premiação com base em participantes
- ⏱️ Bloqueio automático de palpites 60 min antes do jogo
- 📱 Interface responsiva

## 💰 Contribuição e Premiação

- **Taxa de inscrição**: €50,00 por pessoa
- **1º Lugar**: 50% do prêmio
- **2º Lugar**: 25% do prêmio
- **3º Lugar**: 10% do prêmio
- **Custos**: 15% (site, programação, brindes)

## 🎮 Sistema de Pontuação

| Tipo de Acerto | Pontos |
|---|---|
| 🎯 Cravada (placar exato) | 10 pts |
| 👍 Resultado (vencedor correto) | 5 pts |
| 🏆 Campeão | 15 pts |
| 🥈 Vice-Campeão | 15 pts |
| 🥉 Terceiro Lugar | 15 pts |
| ⚽ Artilheiro | 15 pts |
